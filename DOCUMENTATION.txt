                         1. PROJECT OVERVIEW
================================================================================

1.1 Introduction
----------------
The Cafe Management System is a comprehensive web application designed to 
streamline cafe operations. It provides three distinct interfaces for:
- Administrators (cafe owners/managers)
- Baristas (cafe staff)
- Customers (cafe patrons)

1.2 Purpose
-----------
- Eliminate manual order taking
- Reduce waiting time for customers
- Provide real-time order tracking
- Generate sales reports and statistics
- Manage menu items efficiently
- Handle staff management

1.3 Key Benefits
----------------
✓ Digital ordering system
✓ Real-time order status updates
✓ Automated billing calculations
✓ Multi-role access control
✓ Responsive design (mobile-friendly)
✓ Easy menu management

                         3. INSTALLATION GUIDE
================================================================================

3.1 Step-by-Step Installation
-----------------------------

Step 1: Navigate to Project Directory
-------------------------------------
cd "/home/meng/Web Final (Cafe/cafe-app"

Step 2: Install PHP Dependencies
--------------------------------
composer install

Step 3: Configure Environment
-----------------------------
cp .env.example .env
php artisan key:generate

Step 4: Create Database
-----------------------
# SQLite is auto-created, or configure MySQL in .env:
DB_CONNECTION=sqlite
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=cafe_db
# DB_USERNAME=root
# DB_PASSWORD=

Step 5: Run Migrations
----------------------
php artisan migrate:fresh --seed

Step 6: Create Storage Link
---------------------------
php artisan storage:link

Step 7: Start Development Server
--------------------------------
php artisan serve

Step 8: Access Application
--------------------------
Open browser and navigate to: http://localhost:8000

8.1 Authentication Endpoints
----------------------------

POST /api/login
---------------
Description: User login
Request Body:
{
    "email": "user@cafe.com",
    "password": "password"
}
Response:
{
    "success": true,
    "user": {
        "id": 1,
        "name": "John Doe",
        "email": "user@cafe.com",
        "role": "user"
    },
    "message": "Login successful"
}

POST /api/logout
----------------
Description: User logout
Headers: Authorization: Bearer {token}
Response:
{
    "success": true,
    "message": "Logged out successfully"
}

GET /api/user
-------------
Description: Get current authenticated user
Headers: Authorization: Bearer {token}
Response:
{
    "success": true,
    "user": {
        "id": 1,
        "name": "John Doe",
        "email": "user@cafe.com",
        "role": "user"
    }
}

================================================================================
                         10. TROUBLESHOOTING
================================================================================

Problem: Server won't start
---------------------------
Solution: 
- Check if port 8000 is in use
- Try: php artisan serve --port=8080
- Ensure PHP is installed correctly

Problem: Database errors
------------------------
Solution:
- Run: php artisan migrate:fresh --seed
- Check .env database configuration
- Ensure database file has write permissions

Problem: Login not working
--------------------------
Solution:
- Clear cache: php artisan cache:clear
- Clear config: php artisan config:clear
- Verify credentials are correct

Problem: Images not uploading
-----------------------------
Solution:
- Run: php artisan storage:link
- Check storage/app/public permissions
- Verify file upload size in php.ini

Problem: Session issues
-----------------------
Solution:
- Clear session: php artisan session:flush
- Check storage/framework/sessions permissions

Problem: API returns 401 Unauthorized
-------------------------------------
Solution:
- Ensure you're sending auth token
- Token should be in Authorization header
- Format: "Bearer {your-token}"
